# 1200 雅思核心词汇背诵

一个纯前端、可离线、进度存本地的雅思核心词汇背诵网页。用 Edge（或任何现代浏览器）打开即可用，不需要安装、不需要登录、不需要服务器。

**三种练习模式**

| 模式 | 题目 | 作答方式 |
| --- | --- | --- |
| 见词选义 | 给出英文单词 | 四选一挑中文释义 |
| 见义选词 | 给出中文释义 | 四选一挑英文单词 |
| 拼写单词 | 给出中文释义 | 键盘打出英文单词（可按字母给提示） |

还有「混合练习」把前两种随机穿插。

## 现在是什么状态

仓库里目前是 **30 个占位词**，用来先把框架跑通、验收界面与交互。真实词表整理好后，按下面「换成我的 1200 词」一节替换，**界面代码一行都不用改**。

## 怎么用

### 方式一：直接双击（最简单）

下载这个仓库，双击 `index.html`。`file://` 协议下浏览器禁止 `fetch`，程序会自动回退到内联词库 `data/words.js`，功能完全一样。

### 方式二：GitHub Pages（手机也能用）

推送后访问：

```
https://2263318706-commits.github.io/ielts-1200/
```

仓库里已带 `.github/workflows/pages.yml`，推送到 `main` 后会自动发布。如果第一次没生效，去 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**，再手动跑一次 workflow 即可。

### 方式三：本地起个服务器

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000/
```

## 换成我的 1200 词

词表是**数据**，不是代码。整个流程只有两步。

### 第 1 步：填词表

打开 `data/words.csv`（已带 30 行示例），照着改成你的词。表头大小写不敏感，列可以缺、顺序随意：

| 列 | 是否必填 | 说明 |
| --- | --- | --- |
| `word` | **必填** | 英文单词，唯一 |
| `cn` | **强烈建议** | 中文释义；多个义项用 `;` `、` `\|` `/` 分隔，会自动统一成「；」。缺了就没法出选择题 |
| `phonetic` | 建议 | 音标，如 `/əˈbændən/` |
| `pos` | 可选 | 词性，如 `v.` `adj.` `n.` |
| `en` | 可选 | 英文释义，用于排除「看起来也对」的干扰项 |
| `example` | 建议 | 例句；把目标词用 `*单词*` 包起来会自动加粗 |
| `exampleCn` | 可选 | 例句翻译 |
| `tags` | 可选 | 标签/单元，用 `\|` 或 `,` 分隔 |

也可以直接用 JSON：`node scripts/build-data.mjs --in words.json`（结构见 `data/words.json`）。

### 第 2 步：生成数据文件

```bash
node scripts/build-data.mjs --in data/words.csv --strict
```

这会把 CSV 清洗成两个文件（内容一致，分别服务服务器和双击两种打开方式）：

- `data/words.json` —— 网页运行时优先加载
- `data/words.js` —— 内联回退，保证 `file://` 双击也能用

`--strict` 表示缺中文释义就直接报错退出，建议用上，避免词表带着空洞上线。

### 第 3 步：自检

```bash
node scripts/run-tests.mjs
```

会做三件事：词表体检、出题引擎自测、端到端场景回归。

## 功能

- **三种模式 + 混合练习**，随时切换
- **选项个数**可调（四选一 / 六选一）
- **每轮题量**可调（默认 20 题，可设 0 表示一次过完）
- **拼写提示**逐级揭示：不提示 / 只给长度 / 按字母揭示，另有「共 N 个字母」提示
- **答对自动下一题**，可关掉留着看例句
- **错题本**：答错的词自动进本，答对一次自动移出，可一键集中复习
- **发音**：调用浏览器自带语音合成，无需联网音频
- **深色 / 浅色主题**，跟随系统或手动切换
- **键盘操作**：数字键 `1`–`6` 选择，`Enter` 提交 / 下一题
- **进度存本地**（localStorage），可导出/导入 JSON 换设备迁移
- **数据体检**：设置页可看到词表缺音标/缺例句/结构问题的统计

## 目录结构

```
ielts-1200/
├── index.html              入口页面
├── css/style.css           样式
├── js/
│   ├── storage.js          本地存储：设置、进度、错题本
│   ├── data.js             词库加载（json 优先，file:// 回退内联）与自检
│   ├── quiz.js             出题引擎（纯函数，不碰 DOM）
│   └── app.js              界面渲染 / 路由 / 事件
├── data/
│   ├── words.csv           词表源文件 ← 你只需要改这个
│   ├── words.json          生成物：运行时词库
│   └── words.js            生成物：内联回退词库
├── scripts/
│   ├── build-data.mjs      CSV/TSV/JSON → words.json + words.js
│   ├── validate.mjs        词表体检
│   └── run-tests.mjs       自检总入口
└── dev/
    ├── harness.mjs         在 Node 里把网页应用跑起来
    ├── mini-dom.mjs        极简 DOM 实现
    ├── e2e.mjs             端到端场景测试
    └── make-template.mjs   从 words.json 反导出 CSV 模板
```

## 说明

- 所有进程数据只存在**你自己的浏览器**里（localStorage），不联网上传任何东西。
- 词库文件是静态资源，部署到 GitHub Pages 后是公开的。
- 换设备/换浏览器迁移进度：设置 → 数据 → 导出进度，在新设备导入。
